🚀 HOW TO USE:

1. Start Application (same as before)
   • Windows: start.bat
   • Mac/Linux: ./start.sh

2. Access Authentication
   • Navigate to: Sign In / Sign Up (in navbar)
   • Or go to: http://localhost:8000/auth.html

3. Sign Up New Account
   • Click "Sign up here" link
   • Enter username, email, password
   • Click "Create Account"
   • Automatically logged in

4. Login Existing Account
   • Enter username and password
   • Click "Sign In"
   • Redirected to profile page

5. View Profile
   • Click "Profile" in navbar (when logged in)
   • See overview, history, settings

6. Logout
   • Click "Logout" in navbar
   • Session cleared
