# Authentication Quick Start

## 🚀 Get Started in 3 Steps

### Step 1: Run the Application
```
Windows:   Double-click start.bat
Mac/Linux: ./start.sh
```

### Step 2: Create Your Account
1. Wait for browser to open (http://localhost:8000)
2. Click **"Sign In / Sign Up"** in top navbar
3. Click **"Sign up here"**
4. Fill in the form:
   ```
   Username: myusername
   Email: myemail@example.com
   Password: mypassword123
   ```
5. Click **"Create Account"**
6. ✅ Automatically logged in!

### Step 3: Explore
- 📊 View your **Profile** dashboard
- 🔄 Use the **Translator**
- 👁️ Browse **Gestures**
- ⚙️ Update your **Settings**

## ❓ Quick FAQ

**Q: Do I need to sign up?**
A: No! Translator is fully public. Sign up is optional for history.

**Q: Can I use anonymously?**
A: Yes! All features work without login.

**Q: Will my translations be saved?**
A: Only if you're logged in. Anonymous translations aren't saved.

**Q: What if I forget my password?**
A: Password reset isn't yet available. You can create a new account with different email or contact support.

**Q: Can I delete my account?**
A: Yes! Go to Profile → Settings → "Delete Account". ⚠️ Can't be undone!

**Q: Can I change my username?**
A: Not currently. Usernames are permanent at creation.

## 🛠️ Troubleshooting

### "Invalid credentials" when logging in
→ Check username/password (case-sensitive)
→ Make sure account was created

### "Username already exists"
→ Choose a different username
→ Go to login if account exists

### Not seeing Profile in navbar
→ Refresh page (F5)
→ Make sure you're logged in
→ Check browser hasn't cleared cookies

### Translation history empty
→ Make sure you're logged in
→ Perform a translation in translator page
→ Go back to Profile → History tab

## 🔐 Your Data

**What is saved:**
- Username
- Email
- Your translations (gesture + language + date)

**What is NOT saved:**
- Your password (stored securely, never shown)
- Your camera/uploaded images (not stored)
- Your IP address or location

**Privacy:**
- Only YOU can see your profile
- Your data is deleted if you delete your account
- Admin cannot see user passwords
